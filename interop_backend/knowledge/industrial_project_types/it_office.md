---
TITLE: IT and Office Project Service Applicability
TRIGGER: project.project_type == "IT_OFFICE"
CONTENT:
An IT or office project generally requires a physical premises, so the prototype should normally include basic Land/Revenue verification when the company is developing or acquiring a specific site. The interview can ask for location, premises or plot identification, approximate area, and ownership or lawful-use status. If the project is operating from an existing leased office, the platform can use a simpler premises-information path instead of detailed land-record verification.

Electricity verification typically applies because offices and data-intensive facilities require electrical service, although many projects will use an existing commercial connection. The chatbot should therefore ask whether electricity service already exists and obtain the expected load when relevant. Detailed capacity questions can be triggered for requirements above the prototype's 500 kW threshold.

Pollution verification can normally be skipped for a conventional IT or office project when the user reports no industrial emissions, hazardous waste, significant wastewater, or similar environmental activity. If the project includes activities with environmental characteristics outside a normal office, the pollution interview should become active. These are prototype applicability rules, not official regulatory classifications.
